# 部署框架说明

本目录预留后续部署配置，不含已经验证的 Docker 或 K8s 部署清单。

正式部署角色：一个 32 GB DDR3 控制平面、两个各 16 GB DDR3 Worker、独立 32 GB 数据机，四台使用 x86；业务 CPU 暂不指定。数据机采用 2 TB SSD 加 4×2 TB HDD RAID10（约 4 TB 可用），承载 MySQL、Qdrant、资料与本机备份。

独立推理区可选原 GPU 单机、双机或四机 DGX Spark；整套为 5/6/8 台。Spark 每台 128 GB 统一内存，Arm CPU，配 DeepSeek-V4.1-Flash-1017；用户整套价格 8 万/16 万元。跨机互连、量化和 64k 模型能力仍需验证，见 [推理备选说明](../docs/推理服务器备选方案.md)。

配置速览见 [硬件配置概览](../docs/硬件配置概览.md)。节点规格、64k 容量验证、独立备份、SSH/串口边界及待报价清单见 [项目设计方案](../docs/项目设计方案.md)。

当前只需运行 Django 本地框架；无需创建集群、安装推理依赖或连接真实目标设备。
