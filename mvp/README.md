# TermTutor · 单机可运行 MVP

真实终端 + 环境上下文 + 教学助手。此目录是独立实现，保留项目原有 Django 框架与设计资料。

## 直接使用

启动后访问 **<http://127.0.0.1:8765>**。页面、终端和模型接口均可在本机运行。

自行启动时，在项目根目录用 **PowerShell 7** 执行：

```powershell
& 'D:\anaconda\envs\py311\python.exe' mvp/run.py
```

或者在本目录运行：

```powershell
& 'D:\anaconda\envs\py311\python.exe' run.py
```

也可执行 `pwsh -File mvp/start.ps1`。默认端口 8765；若被占用，可添加 `--port 8766`。前台运行时按 Ctrl+C 停止服务；停止后交互终端一并结束，学习记录保留。

首次使用时，在自己的 Conda `py311` 环境安装依赖；示例解释器路径请按本机安装位置调整：

```powershell
& 'D:\anaconda\envs\py311\python.exe' -m pip install -r mvp/requirements.txt
```

要求 Python 3.11 和 PowerShell 7。浏览器用 Chrome / Edge 即可。前端终端资源已随目录提供，运行时不访问 CDN，也不需要 npm 构建、Docker、K8s、MySQL 或独立向量数据库。

## 五分钟体验

1. 打开页面，点击“打开本地 PowerShell”。会话初始位于 `mvp/data/workspaces/<会话ID>/`，每个会话独立。
2. 依照 PowerShell 入门课程，亲自输入 `Get-Location`、`Get-ChildItem` 等命令，观察实际结果。
3. 在右侧询问“解释刚才的输出”或“给我下一步提示”。模型可以读取本次会话近期输出，并调用只读环境观察、资料检索工具。
4. 点击“我已完成这一步”保存进度。完成标记是**学生自评**，不是自动判题结果。
5. 刷新页面后仍可查看对话和进度；也可从右上角导出 JSON 记录。

原始终端输出只在内存中保留最近约 60,000 字符，不作为终端日志写入数据库。选中“附带当前终端输出”时，问答会向你配置的模型发送最近最多约 10,000 字符的输出。教学问答文本、答案和检索出处会保存到本机 SQLite。

## 本机模型

支持已有的 OpenAI 兼容聊天服务。在“模型设置”中填写服务地址和服务端实际模型 ID，或参照 `.env.example` 创建本地 `.env`；真实配置不随 Git 提交。Base URL 应包含服务的 API 前缀，程序追加 `/models` 和 `/chat/completions`。

在“模型设置”里也能修改地址、模型名、Key，或关闭模型问答；界面修改只在本次进程运行中生效。API Key 不回显、不写入学习库。配置文件用于需要长期保留的设置。新机器可复制 `.env.example` 为 `.env` 后填写；若未填写模型名则启用离线教学。

模型服务需自行保持运行。本 MVP 不会下载几十 GB 的权重，也不会自动启动或更换推理模型。服务暂不可用时，界面会说明错误并标注“离线讲义”，提供规则与讲义提示，不伪装成模型回答。

## SSH / 串口说明

点击左侧“新建终端连接”，切换相应页签。

- SSH 首次连接会展示服务器主机指纹。通过可信渠道核对后勾选确认，再次连接；已信任的主机密钥保存于 `data/known_hosts`。已知主机密钥变化时连接失败，不自动接受新密钥。
- SSH 的密码和私钥口令只用于建立连接，不写入数据库；私钥路径从本机读取，不传给模型。
- SSH 和串口只分析当前交互通道已有输出，不使用另一条 exec 通道猜测工作目录或激活环境。远程目录未知时明确显示未知。
- 串口要求设备已被系统枚举，先确认端口、波特率和占用状态。设备可能在打开串口时因 DTR/RTS 默认电平而复位；请按具体设备条件使用。

## 本版取舍

为在三小时内交付可用闭环，采用 **FastAPI + 单进程终端管理 + SQLite + 静态前端**，与现有 Django 框架隔离。客户端和服务都在同一台电脑，仅监听 `127.0.0.1`。

本版没有引入 Electron 安装包、Pi SDK、账号体系、多人服务、远程部署、Qdrant、嵌入模型、SFTP 或任意远程探查命令。课程资料检索是可解释的本地词法检索，**不是向量 RAG**。后续可再将已验证的终端与教学闭环迁回正式桌面架构。

嵌套执行 `ssh`、`docker exec` 或进入 Pod 后，本地目录提示只代表最后一次本地提示符的证据，不代表内部目标。建议使用独立 SSH 会话，提问时说明当前目标。不可用的 Docker/K8s、远端权限或 Shell 状态不会被推断成已可用。

终端中的命令会真实操作电脑，本版不提供操作系统级沙箱。练习目录便于整理文件，但并非文件访问隔离。模型输出仅作教学提示。

## 轻量验证

```powershell
# 默认不调用模型，隔离临时数据，检查终端及核心业务闭环
& 'D:\anaconda\envs\py311\python.exe' mvp/smoke.py

# 额外对本地 .env 配置的模型做一轮真实流式问答与工具调用
& 'D:\anaconda\envs\py311\python.exe' mvp/smoke.py --model

# 一次预热、三次串行短输出；结果写入已忽略的 data/
& 'D:\anaconda\envs\py311\python.exe' mvp/benchmark.py
```

`--model` 检查读取本地 `.env`，也可用 `--model-base-url` 和 `--model-name` 显式指定。测速使用服务端返回的 token 计数，不把字符数换算成 token；短提示与预热缓存会影响结果。
